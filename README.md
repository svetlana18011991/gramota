# Лист — редактор дипломов и грамот

Откройте **index.html** двойным кликом. Редактор работает полностью офлайн: шрифты встроены в файл, устанавливать программы, запускать сервер или использовать npm не нужно.

## Как создать диплом

1. Выберите книжный или альбомный лист A4.
2. Загрузите фон в формате **JPEG, PNG или WebP**.
3. Добавьте текстовые поля, линии или прямоугольники. Слева находятся настройки, справа — предпросмотр листа.
4. Выберите объект на листе и перетащите его в нужное место. Потяните угловой маркер, чтобы изменить размер. Шрифт, размер, цвет и другие свойства выбранного объекта можно настроить слева.
5. Нажмите **«Сохранить PDF»**, чтобы скачать готовый лист A4 с разрешением 300 dpi. PDF растровый: надписи становятся частью изображения и не сохраняются как редактируемые текстовые объекты.

## Как продолжить редактирование позже

Сохраните проект в файл **.diploma.json**. Он включает фон и редактируемые объекты со всеми настройками. Чтобы вернуться к работе, откройте редактор и загрузите этот файл проекта.

Редактор также сохраняет локальный черновик в браузере. Для больших фоновых изображений браузер может не сохранить черновик — в этом случае редактор покажет «Сохраните проект в файл». Черновик привязан к браузеру и месту открытия страницы; очистка данных браузера может его удалить. Для переноса на другой компьютер или надёжного хранения скачивайте файл проекта.

## Клавиши

| Действие | Сочетание |
| --- | --- |
| Отменить действие | Ctrl/Cmd + Z |
| Повторить действие | Ctrl/Cmd + Shift + Z |
| Сохранить проект | Ctrl/Cmd + S |
| Дублировать выбранный объект | Ctrl/Cmd + D |
| Удалить выбранный объект | Delete |
| Сдвинуть выбранный объект | Стрелки |
| Сдвинуть с шагом в 10 раз больше | Shift + стрелки |

При вводе текста клавиши редактирования работают с полем ввода.

## Размещение на GitHub Pages

1. Создайте репозиторий на GitHub. Для бесплатного GitHub Pages используйте публичный репозиторий.
2. Выберите **Add file → Upload files**, загрузите **index.html** в корень репозитория и сохраните изменения кнопкой **Commit changes**.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Source → Deploy from a branch**.
5. Укажите ветку **main**, папку **/(root)** и нажмите **Save**.
6. Дождитесь публикации. Адрес сайта появится в разделе **Pages**; обычно он выглядит как `https://имя-пользователя.github.io/имя-репозитория/`.

Для размещения достаточно одного файла **index.html**. Отдельный workflow не требуется.

## Встроенные шрифты

Cormorant Garamond, Playfair Display, Marck Script, Caveat, Montserrat и PT Serif с кириллицей; системные Georgia, Arial и Times New Roman. Свободные шрифты распространяются по SIL Open Font License; тексты лицензий включены в index.html.

Фон: до 15 МБ, PNG/JPEG/WebP. До 250 элементов на листе. На телефоне предпросмотр расположен над настройками.
